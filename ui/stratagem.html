Appui bref : envoie le code et lance le compte a rebours. Appui long : remet le compteur a zero (utile si le stratageme n'a pas ete lance). Le jeu ne communique rien : le compte a rebours est une estimation qui demarre a l'appui, alors que la recharge reelle demarre a l'explosion de la balise. Les temps des prereglages changent a chaque patch — le champ Recharge permet de les corriger. Le jeu doit etre configure en mode APPUI (et non maintien) pour la touche stratageme.
